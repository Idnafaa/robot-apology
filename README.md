A two-line robot apology: a household robot owns setting the alarm for 7 p.m. instead of 7 a.m., and learns to say the hour out loud and wait for a nod before setting anything.

## Run it

```sh
python3 main.py
```

The program writes the two-line apology to `/output/entry.txt` (351 characters, two sentences).
